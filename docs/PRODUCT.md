# 產品規格：本機優先 PWA

## 核心流程

免帳號開啟 → 輸入文字／貼上或選擇圖片／錄短語音 → 本機模型解析 → 可編輯標題、正文與發生時間 → 確認保存 → 本機搜尋與修改。

不保留原始圖片或錄音；頁面暫存媒體在保存／離開後釋放。每次 AI 的草稿及辨識內容都可能出錯，用戶確認是必要步驟。未通關、未付款等狀態不能推測為已完成；無法確認的標題可能留白。

無登入、金流、訂閱、群組、管理後台、自動同步或背景推播。待辦到期時間僅供列表查看。搜尋、歷史及刪除還原不需要網路。AI 摘要最多讀取目前前 400 筆紀錄並提示截斷；摘要不自動存成紀錄。

## 本機資料與備份

IndexedDB 保存紀錄、修改前快照與待辦。每筆資料有本機數字編號與可跨備份辨識的 UUID，匯入時重新分配本機數字編號。刪除是移至已刪除清單，可還原；仍會包含在備份中。

匯出預設包含已刪除紀錄、完整修改歷史與待辦，不含帳密、模型、原圖或錄音。可按日期分批匯出，或明確選擇略過歷史、只備份目前內容。匯出日期範圍依瀏覽器本地日期套用，紀錄採發生時間，無發生時間及待辦採建立時間。

匯入先驗證，再預覽新增／重複／衝突筆數。確認前不寫入。相同 UUID 與相同內容會略過；不同內容預設保留本機，可選保留兩份，絕不直接覆寫。重複匯入相同衝突內容不會持續新增相同副本。匯入是合併，不是自動同步，也不會依匯入檔刪除本機資料。

JSON 備份沒有加密，需由用戶自行妥善存放。單檔最多 20 MB、紀錄與待辦合計 10,000 筆。檔案過大可按日期分批，或不含歷史。切換網站網址、瀏覽器、設定檔或裝置時需要自行匯出／匯入。

## 離線與更新

網站第一次使用需連網完成 App shell 與模型下載。之後可離線操作已快取的模型；未下載模型無法憑空離線使用。模型快取與紀錄分開，清除模型快取不刪除紀錄。清除全部網站資料則兩者都可能消失。

瀏覽器是否允許持久儲存由瀏覽器決定，即使申請成功也不能替代外部備份。提供新版本提示，用戶先保存草稿再明確更新；不強制在輸入中重載。iOS／Safari 實際 WebGPU 與空間限制仍取決於裝置。

## 取代原版功能

AI 提示／模型改為版本化靜態設定；客服錯誤管理改為本機固定代碼診斷匯出，不自動回報。用戶列表與帳號／角色管理移除。舊雲端資料不自動搬移，原版分支保留舊流程與資料存取工具。

## 2026-11-01 語音輕量試用

目前主模型改為 Whisper base Q8，實測模型及必要設定快取約 79.7 MB，沒有大型備援。此版本在收款金額與姓名測試發現誤識，不能宣稱已達可靠繁中辨識；用戶可在 AI 整理前修正逐字稿，最後確認保存。詳見 [試用結果](WHISPER_BASE_TRIAL.md)。
