# AFTERTRACE 本機 AI 決策 — 2026-10-28

此文件記錄使用者最新決策，優先於舊版雲端 AI、點數、媒體及擴充功能規範。

## 推論與資料邊界

- 所有 AI 推論在使用者瀏覽器裝置完成，使用 WebGPU；不提供雲端推論或雲端備援。
- 模型與 ONNX Runtime 靜態資源首次由 Hugging Face／版本化 CDN 下載。下載資源不等於傳送使用者內容進行推論；瀏覽器可能清除快取。
- 文字／圖片：Transformers.js 4.3.2、Qwen3.5-0.8B ONNX-OPT 量化模型；短語音：Whisper small 多語言 ONNX 量化模型。
- 不使用可能連接供應商伺服器的 SpeechRecognition／webkitSpeechRecognition。
- 圖片與錄音不傳到後端、不保存原始媒體。後端僅在使用者確認後接收文字紀錄，仍執行帳號／群組權限及版本驗證。
- `/api/v1/ai/*` 在正式 Worker 回傳 410 LOCAL_AI_ONLY，舊客戶端也不能啟動供應商呼叫。
- 舊 provider 模組及測試暫留作歷史邏輯，已移出正式 Worker 的路由及依賴圖，不可重新接線。

## 輸入與確認保存

1. 接受直接輸入文字、貼上單張圖片、選擇單張圖片，或使用者主動錄製短語音。
2. 圖片僅 PNG／JPEG／WebP，最多 5 MiB。圖片解碼後上限 2500 萬像素，推論時最長邊縮至 1024。
3. 不接受 PDF、文件、任意附件或音訊檔上傳。截圖視為圖片，不提供獨立的擴充功能截圖擷取入口。
4. 錄音最多 60 秒，自動停止；音訊在裝置解碼為 16 kHz 單聲道，由本機 Whisper 辨識。語音語言由使用者選擇中文／英文，預設中文；目前套件未實作自動語言偵測，不可宣稱自動辨識語言。
5. 辨識文字保留在輸入區；AI 解析只產生標題、內容草稿。發生時間依輸入的明確日期／時間在本機確定性解析後帶入，可手動修改；只有時刻時使用裝置今天日期並提示，歧義時留白。不採用模型自行產生的日期欄位。
6. 使用者可修改標題、內容及時間，按「確認保存」才建立正式紀錄。
7. 已編輯的草稿不被重新解析覆蓋；返回輸入前確認捨棄。保存失敗保留草稿，解析失敗保留輸入。
8. 模型載入／推論顯示狀態，可取消；Web Worker 避免阻塞畫面。取消、離開頁面應釋放錄音與運算資源。
9. 不支援 WebGPU、記憶體不足或下載失敗時顯示原因，保留手動編輯／確認保存。

## 其他 AI 工具

- 自然語言搜尋在本機解析條件，後端執行授權後的確定性查詢。
- 摘要、相關紀錄、改寫、待辦建議均在本機推論；改寫和建立待辦仍需明確確認。
- 摘要／紀錄工具最多讀取授權範圍內 400 筆；摘要分段處理並顯示截斷狀態。相關紀錄最多比對 40 個候選，介面必須揭露限制。
- 模型產生的待辦時間不直接採用，由使用者確認／填寫，避免日期誤判。
- 不會自動回填歷史紀錄或自動建立待辦。

## 商業與既有資料

- 本機 AI 不使用舊雲端 provider 點數／成本准入。
- 最新決策：產品無訂閱與金流。正式 Worker 不載入金流／訂閱路由；所有 /api/v1/payments/* 與 /api/v1/subscription/* 回傳 410 BILLING_RETIRED（OPTIONS 僅供 CORS）。前台不查詢方案、不提供結帳／取消／付款回呼。
- 歷史帳務資料與舊實作保留供查閱；停用程式不會替外部供應商取消既有合約，本次沒有對供應商操作。
- 舊帳務／點數表暫時保留，不清空資料庫、正式付款回呼已停用。
- 不再要求 GEMINI_API_KEY、雲端模型價格或 AI 試用額度才能通過服務 readiness。
- GitHub Actions 不得啟動；此改造只執行本機測試及 build dry-run，不部署、不推送。

## 驗證要求

- typecheck、lint、API／Web／Admin tests、四個應用 build。
- 介面測試：解析不寫入、確認後保存修改內容、失敗保留、拒絕文件、草稿不被覆蓋。
- 正式 Worker 測試：所有舊 AI 入口不執行資料庫、供應商或保存操作。
- 真實 Chrome：WebGPU、文字／圖片／語音模型載入與推論；確認保存、桌機／手機排版。
- 真實模型可執行不等於繁中辨識品質驗收完成。需另外用實際圖片、繁中錄音及目標手機驗收。

## 本機體驗優化

- 首頁先顯示最近 5 筆，可展開至 10 筆；長內容收合。
- 摘要僅按鈕觸發，每段最多 320 tokens、提示最多 5 個重點，逐段顯示並可取消，已完成部分保留。
- 前端站內導航保留閒置模型，處理中離頁取消；閒置 5 分鐘釋放。登出仍完整刷新。
- 「本機 AI」頁顯示模型資源快取與儲存估計，可單獨清除 transformers-cache，不清除登入或紀錄。
- 最新介面決策：移除原文對照與文字差異兩個區塊，保留標題、內容、可修改發生時間及明確確認保存。

## 記錄頁預載與情境（最新）

- 使用者進入記錄頁、完成範圍授權後，背景下載並載入文字／圖片模型；不需要先按 AI 解析。不自動推論或保存。
- 顯示準備進度，可暫停；準備中按解析共用同一份預載 Promise 與 Worker，不重複建立。準備失敗仍可手動保存，之後解析可重試。
- 語音模型仍於錄音功能使用時按需準備，避免進頁同時下載兩套大模型。
- 提示改為依工作／生活／遊戲情境整理紀錄，遊戲副本與檔案副本依上下文保留含義，不自行新增遊戲名稱或結果。

## 資料庫提示管理（最新）

- 六種提示：文字／圖片整理、自然語言搜尋、待辦建議、改寫、相關紀錄、區間摘要。正式提示來自 worklog_local_ai_prompts，不再硬編碼在前台。
- config/local-ai-prompts.seed.json 只提供首次初始化與固定變數／JSON 契約定義。種子寫入使用 ON CONFLICT DO NOTHING，不能覆寫管理員已編輯的資料。
- 後台 /ai?tab=prompts 可儲存草稿、預覽組裝文字、發布、檢視最近 20 筆歷史及回復已發布版本。回復會覆蓋目前草稿並立即發布，介面必須先確認。
- 草稿與發布內容獨立。所有修改使用 expectedVersion，單一 SQL 原子更新並寫入歷史；衝突回傳 409，保留使用者尚未保存的文字。
- 模板最多 4000 字，輸出上限 64～768 tokens；保留該功能必要變數與 JSON 欄位。日期計算、權限、輸出解析及確認保存仍由程式保護，不可由提示繞過。
- 前台 GET /api/v1/local-ai/prompts 為公開唯讀設定，只傳已發布模板、上限及版本，不包含草稿或管理員資料。提示本來就會給瀏覽器，不能存放密鑰或私人資料。
- 每次 AI 操作取得／重新確認發布設定（ETag／304、進行中請求合併）；同一次摘要固定使用同一份設定快照。設定失敗顯示中文錯誤，保留手動操作，不使用硬編碼或雲端 AI 備援。
- 管理 API /api/v1/admin/local-ai-prompts 使用管理員 session 與來源限制，不接受一般使用者 session。公開預覽代理仍封鎖全部管理 API。
- 模型下載與運算仍在瀏覽器；使用者輸入只在本機代入模板。Whisper 語音辨識的語言／task 選項不是自然語言提示，仍由程式管理。
- schema／canonical baseline／snapshot 已同步提示、角色、管理帳號、模型表與完整 COMMENT。既有本機 Docker 由 integration:db 加入缺少的 prompt 表後種入初始設定，不清空資料。

## 模型與後台設定（2026-10-29）

- 模型 ID 與固定 commit revision 存 worklog_local_ai_models，/ai?tab=models 維護相容選單與自訂代碼。預設 Qwen／Whisper 為初始化值，不是前台固定模型。
- 每次操作重新確認設定版本（ETag／304、進行中請求合併）；提示及模型設定 HTTP 讀取 15 秒逾時，不沿用過期設定默默推論。
- 快取由瀏覽器以下載資源 URL／版本管理，沒有本機固定磁碟路徑的保證；換模型／固定版本可能重新下載。
- 管理員登入與權限見 [後台管理規範](WORKLOG_ADMIN_POLICY.md)。

## 繁中品質與核對（2026-10-29）

三種離線 zh-TW 合成語音測試中有兩組近音誤字，不能宣稱人名／專有名詞必然正確。錄音提供僅存本頁的重聽入口，明確提示核對人名、金額與否定狀態。確認保存後移除錄音與 URL；媒體仍不傳後端。AI 標題若加入無根據銀行／提款情境，或與否定／未完成狀態有風險，保守留白並提示用戶核對；此規則不是完整事實驗證。詳見 TRADITIONAL_CHINESE_CONTENT_QUALITY.md。


## 繁中語音模型更新（2026-10-29）

本機預設語音改用資料庫指定的 Whisper large-v3-turbo，新增 Breeze ASR 25 與 medium 後台選項，加入離線繁體轉換與靜音檢查。13 組保存整合測試全數保存一致；原始語音 2/3 正確，仍有「尾款」同音字問題。比較、資源限制與完整結果見 [瀏覽器繁中語音模型評估](LOCAL_ASR_MODEL_EVALUATION.md)。其他環境的既有模型設定不會被初始化種子覆寫。

目前預設 large-v3 優先、turbo 為用戶可選備援，兩者代碼／revision 存資料庫。加入容量估算、保留原錄音切換、裝置偏好與重設、30 秒等待提示，以及取消預載的競爭保護。詳見 [語音備援整合驗證](LOCAL_SPEECH_FALLBACK_VALIDATION.md)。
