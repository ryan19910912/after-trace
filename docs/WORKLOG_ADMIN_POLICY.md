# 管理後台規範

更新：2026-10-30。

## 頁面

- /users：用戶列表預設 10 筆，可選 10／25／50，列用戶 ID、建立時間、最後使用時間、歷史保存紀錄。支援 ID／名稱搜尋，依最後使用時間由新到舊排序，尚無使用時間者置後、相同時間按 ID 由新到舊。每頁筆數選擇放於底部分頁列、頁碼右側；歷史以作者範圍分頁，完整文字按需讀取。
- /ai?tab=prompts：提示詞草稿、預覽、發布、歷史及回復；/ai?tab=models：模型下拉選單或相容自訂代碼。
- /feedback-management：類別、狀態、內容、用戶 ID 及可讀使用資訊，不直接呈現 JSON。
- /announcements：公告草稿、全部／指定用戶、排程及明確發送。
- /roles、/permissions、/admin-accounts：角色、各頁查看／操作權限、後台帳號。

舊營運總覽、歷史方案、本機 AI 管理頁、AI 成本與點數報表不再提供。/ai-prompts 等舊前端網址導向有權限的現行頁，舊管理 API 依路由回傳退役狀態，不是仍開放的功能。

## 角色與帳號

預設 MANAGER「管理者」與 OPERATOR「營運者」，可建立額外角色；預設角色不能刪除，使用中的角色也不能刪除。角色權限分頁查看／操作，操作必須同時有查看，歷史查看需同時有用戶列表權限。

初始化最高帳號 admin 使用亂數密碼，僅首次寫入 bootstrap receipt，檔案不可提交。密碼加鹽雜湊，ADMIN_PASSWORD_PEPPER、ADMIN_SESSION_SECRET 應分環境且長期安全保存；遺失或更換 pepper 會使既有密碼驗證失敗，不可每次啟動重產。

最高帳號永遠有全部權限，不能被停用、改角色或由他人重設密碼；管理者也不能停用或改自己的角色。所有帳號可用目前密碼修改自己的密碼。新建／重設提供臨時亂數密碼並強制首次修改。成功後頁面顯示此次密碼及對應帳號，可複製、隱藏或關閉；剪貼簿不可用時選取文字供手動複製，離頁不保存明文。

簽章 session 最長 12 小時，API 每次讀目前帳號／角色／token_version。密碼更新、停用及管理帳號設定更新撤銷舊登入；角色權限變更下一次請求生效。登入連續失敗會暫時鎖定。

## AI 與客服

模型來自 Hugging Face 相容 ONNX 倉庫，資料庫保留固定 commit revision；已列選項與自訂代碼都不能切成伺服器推論。新模型下次 AI 操作套用，可能需要重新下載；相容格式不代表已完成品質驗收。

提示公開讀取只含已發布設定，不能放密鑰／私人內容。提示和模型變更以 expectedVersion 防止互相覆蓋；未保存離開需提示。

客服應向用戶索取頁首的用戶 ID，在用戶列表反查；不是索取第三方 email／密碼。回饋未知 context 欄位不直接輸出給客服。歷史讀取失敗須可重試。

公開前台預覽代理封鎖全部管理 API，後台維持本機入口。權限保護必須在 API 執行，不能只藏選單。

## 查閱稽核與帳號分頁（2026-10-29）

查閱歷史前先選用途（SUPPORT_REQUEST／DATA_REVIEW）並按開始查閱。API 缺少合法用途回 400；每次列表／全文讀取與 audit INSERT 在同一 SQL 執行，寫入失敗不回傳正文。稽核含管理帳號、時間、目標用戶／紀錄、用途及分頁，不複製正文。全文找不到或作者不符不建立成功查閱紀錄；權限仍由中央 middleware 驗證。稽核目前保存在 worklog_audit_logs，沒有另增稽核列表頁。

管理帳號頁移除搜尋與分頁，直接列出全部帳號；使用已授權的 /staff?all=true，舊 API 分頁仍保留相容。欄位為帳號、角色、啟用狀態、創建日期、最後登入日期及操作。操作提供禁用／啟用、重設密碼，最高帳號及本人受保護；重新載入忽略過期回應。回饋有權限時可跳到已按用戶 ID 篩選的用戶列表。


## 逐頁操作與恢復檢查（2026-10-30）

已補上共用請求逾時／錯誤恢復、公告唯讀與鍵盤操作、角色草稿保留、提示詞版本重試、明確備援停用選項、彈窗及手機標籤排版。詳見 [逐頁複查報告](ADMIN_FULL_REVIEW_2026-10-30.md)。錯誤集中收集仍為建議方案，尚未新增資料庫表與後台頁。


## 錯誤紀錄管理（2026-10-30）

新增 `/error-logs` 與 errors.read／errors.write 權限，顯示可讀摘要、用戶 ID 及 requestId／eventId，支援查詢與處理狀態。只存白名單 metadata；詳細限制與本地整合測試見 [錯誤紀錄管理實作與驗證](ERROR_LOGGING_IMPLEMENTATION.md)。採 0001_error_logs.sql 新增遷移，保留既有基底與資料；既有角色不自動增加權限。
